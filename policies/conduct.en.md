# Code of conduct

Last updated: 2026-11-19.

This code applies to the issues and pull requests of this repository, and to every place of a collaboration started here.
It applies to the operator as well.

## Expected conduct

- Writing about claims and evidence, not about the person who holds them.
- Correcting an error that has been pointed out, without deleting the record.
- Citing only evidence whose source is known.
- Stating what a language model was used for, when one was used.
- Not using another person's unpublished draft or idea without that person's agreement.

## Conduct not accepted

- Harassment, threats, or words that demean a person.
- Discrimination by nationality, gender, age, disability, belief or the like.
- Writing another person's personal data without that person's agreement.
- Harming another person's reputation or credibility.
- Falsifying data or sources.
- Asking for, or offering, money or any other consideration.

## How to report

Conduct against this code can be reported through the [request form](https://github.com/cpsbvbng26-dotcom/research-collaboration/issues/new?template=request.yml).
When it cannot be written in public, the kind "Ask for a private answer" is chosen in that form.
The procedure is under "Requests that cannot be made in public" in [Requests](./requests.en.md).
That section also gives the email route, without opening an issue.

## What the operator does

The operator reads every report.
The operator may hide or delete a post that breaks this code, lock an issue, or block an account from this repository.
All of these are done with GitHub's features.
The operator writes what was done in the issue, as far as it is safe to say.
The same applies when the operator breaks this code.
