# 削除・訂正・開示の求め

最終更新：2026-11-19。

## 求めることができるもの

- 自分についての記載の訂正・削除。
- 名の示し方の変更・名を外すこと。
- 保有個人データの利用目的の通知・開示・訂正・追加・削除・利用停止・消去・第三者への提供の停止。
- 自分の個人情報の削除。
- 自分の名誉や信用を傷つける内容の削除。
- 自分の権利を侵す内容の削除。
- 言語モデルに渡すことへの同意の撤回。
- 行動の決まりに反する振る舞いの知らせ。
- 運営者の住所を知ること。
- 非公開の連絡を求める。

費用はかかりません。
求めは、住んでいる国や国籍を問わず、同じ手順で受けます。
日本語でも英語でも受けます。

## 求め方

[削除・訂正・開示の求め](https://github.com/cpsbvbng26-dotcom/research-collaboration/issues/new?template=request.yml)の様式で issue を開きます。
どの記載について、何を求めるかを書きます。
問題の個人情報そのものは書き写さず、どこにあるかだけを書く形にしています。
求めは、この様式のほか、運営者の[免責事項](https://github.com/cpsbvbng26-dotcom/cpsbvbng26-dotcom/blob/main/DISCLAIMER.md#情報の扱い)にあるメールの宛先でも受けます。
その宛先は、運営者のほかのリポジトリと同じ既存のもので、このリポジトリのために作ったものではありません。
このリポジトリのために、新しい連絡先は作っていません。
求めは、代理人が出すこともできます。
そのときは、本人の GitHub アカウントから、代理を頼んだことを issue に一言書く形にしています。

## 公開できない求め

公開の場で書けない事情があるときは、issue を開かずに、免責事項のメールの宛先へ求めを送ることができます。
運営者は、そのメールに非公開で答えます。
求めた人が、自分の連絡先を公開する必要はありません。
運営者の住所を求めるときも、この宛先で受け、遅滞なく答えます。
様式の種類で「非公開の連絡を求める」を選び、ほかの欄を空のまま出すこともできます。
issue に出るのは、GitHub のアカウント名と題と種類だけです。
求めた人が自分の GitHub のプロフィールに連絡先を公開しているときは、運営者はその連絡先へ非公開で答えます。
そうした連絡先が無いときは、個人の事柄を書かずに、issue でメールの宛先のある免責事項を示します。
安全の問題の知らせ方は、[SECURITY.md](../SECURITY.md) にあります。
その入口は、運営者のほかのリポジトリと同じもので、このリポジトリのために作ったものではありません。
SECURITY.md は、運営者のほかのリポジトリと一字一句同じ写しです。
その中の「免責事項」は、運営者の免責事項のことで、このリポジトリの[免責事項](./disclaimer.md)ではありません。
その中の確かめた日は、写しのもとのリポジトリで確かめた日です。
このリポジトリでも GitHub の非公開の脆弱性報告が有効でないことを、2026-11-19 に GitHub の API で確かめました。

## 求めを受けた後

運営者は、それぞれの求めに 7 日以内に答えることを目指します。
個人情報の露出のように害が大きいものは、判断の前に、その記載を外します。
他人の名誉や信用を傷つける記載も、判断の前に外します。
外したことが正しくなかったと分かったときは、元に戻し、書いた人に issue で知らせます。
名の示し方の変更と、名を外すことには、理由を問わず応じます。
開示は、求められた方法で行います。
電磁的記録で求められたときは、電磁的記録で渡します。
求めに応じたときは、何をしたかを遅滞なく知らせます。
求めに応じないときは、その理由を答えます。

## 外せないもの

リポジトリの過去の版は、履歴を書き換えない限り残ります。
ほかの人がすでに写したものは、運営者の手の外にあります。
履歴から消す必要があるときは、運営者が GitHub にその削除を求めます。
すでに出た稿に印字された名は、その場の手続きによらなければ変わりません。
