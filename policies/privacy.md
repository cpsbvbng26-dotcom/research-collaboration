# 個人情報の取り扱い

最終更新：2026-11-19。

## 取り扱う者

このリポジトリを運営するのは、GitHub のアカウント cpsbvbng26-dotcom の持ち主である個人、根本卓哉（Takuya Nemoto）です。
運営者の住所は公開していません。
住所は、求めた人に遅滞なく知らせます。
求め方は、[削除・訂正・開示の求め](./requests.md)の「公開できない求め」にあります。
法令の読み方は、[法令の整理](./law.md)の「個人情報保護法」にあります。

## 集めるもの

このリポジトリは、GitHub の issue の様式に書かれたものと、運営者の[免責事項](https://github.com/cpsbvbng26-dotcom/cpsbvbng26-dotcom/blob/main/DISCLAIMER.md#情報の扱い)のメールの宛先に届いた求めと知らせを扱います。
issue で扱うのは、GitHub のアカウント名と、様式に書かれたことです。
メールで扱うのは、送った人のメールアドレスと、メールに書かれたことです。
本名・住所・所属・連絡先は求めません。
病歴や心身の状態などの要配慮個人情報も求めません。
様式も、これらを書かない形にしています。
このリポジトリは、サイトも、cookie も、アクセス解析も持ちません。
GitHub の画面を見たときの記録は、GitHub が自身の方針で扱います。

## 利用の目的

- 共同研究の申し出を読み、答えること。
- 合意した協力を進め、誰が何をしたかを記すこと。
- 削除・訂正・開示などの求めに応じること。
- 誤りの知らせと権利者の知らせを扱うこと。

運営者は、これらのほかには使いません。
メールの宛先に届いたものも、同じ目的にだけ使います。
誤りの知らせの様式で開かれた issue と、メールで届いた求めには、運営者の免責事項の「情報の扱い」の節も掛かります。
このリポジトリのために作った様式は、書く欄より前に、この目的を書いています。

## 公開されること

issue は公開されます。
書いた本人が、GitHub の公開の場に出すものです。
GitHub（米国）は、その規約と方針に沿って、issue を保存し、表示します。
GitHub の利用規約は、issue を含む内容を、GitHub とその関連会社が AI の機能とモデルの学習に使うことを認めています。
その句は、[法令の整理](./law.md)の「GitHub の利用規約」に引いています。
運営者は、この使い方を止められません。
運営者は、GitHub を、運営者に代わって個人データを扱う委託先とは扱いません。

## 言語モデルに渡すこと

運営者は、このリポジトリの作業を Claude Code で行います。
様式の同意の欄に印のある issue に限り、その題と本文を、Claude（Anthropic、米国）に渡すことがあります。
運営者は、これを個人情報保護法第28条の外国にある第三者への提供として扱います。
同意の欄の英語の文は「I consent to the operator giving the title and text of this issue to Claude (Anthropic, United States).」です。
米国の制度と Anthropic の措置は、運営者の[免責事項](https://github.com/cpsbvbng26-dotcom/cpsbvbng26-dotcom/blob/main/DISCLAIMER.md)の「issue の中身と言語モデル」の節にあります。
その節は、個人情報保護委員会の頁と Anthropic のプライバシーポリシーから句を引いています。
申し出・求め・権利者の知らせの様式は、このリポジトリのために作った様式です。
これらの様式では、印は任意です。
印が無い issue は、運営者が、Claude にもほかの言語モデルにも渡さずに扱います。
誤りの知らせの様式は、運営者のほかのリポジトリと一字一句同じ写しです。
その様式では、同意の欄は必須です。
その様式は、同意しないときは、免責事項のメールの宛先で誤りを知らせることもできると書いています。
issue のコメントは、言語モデルに渡しません。
メールの中身も、言語モデルに渡しません。
同意は、issue かメールで、いつでも撤回できます。
撤回のあとは、その issue を言語モデルに渡しません。
運営者が自分で開いた issue は、この限りではありません。

## そのほかの第三者

運営者は、上のほかに、個人データを第三者に渡しません。
法令に基づく場合は別です。
運営者は、個人データを第三者から受け取りません。

## 保存の期間

issue は、削除の求めがあるまで残します。
協力した人の名と役割は、出したものの記録として残します。
求めがあれば、名の示し方を変えるか、名を外します。
ただし、すでに出た稿に印字された名は、運営者の手では変えられません。
リポジトリの履歴と、ほかの人がすでに写したものには、記載が残ることがあります。
GitHub は、issue の動きを、通知を受け取る設定のアカウントに知らせます。
通知は、受け取る人の設定によって、issue の中身の写しを含む電子メールとしても届きます。
issue を消しても、すでに届いた通知の写しが消えるとは限りません。

## 安全のための措置

運営者は、issue に書かれたものを、ほかの場所に集めません。
同意のある issue の題と本文を Claude に渡すほかは、運営者は写しを作りません。
GitHub の通知が届ける写しは、上の「保存の期間」のとおりです。
このリポジトリを変えられるのは、運営者の GitHub アカウントだけです。
変更は、公開の履歴にすべて残ります。

## 漏えいなどが起きたとき

個人データの漏えいなどで、法律が報告を求める事態が起きたときは、個人情報保護委員会に報告します。
本人には、本人が開いた issue で知らせます。
メールで届いたものについては、そのメールを送ってきた宛先へ知らせます。
運営者の GitHub アカウントが乗っ取られて issue が書き換えられたときも、この事態として扱います。
法令の読み方は、[法令の整理](./law.md)の「漏えいなどが起きたとき」にあります。

## 求め

自分についての記載は、訂正・削除・開示・利用停止を求めることができます。
費用はかかりません。
手順は[削除・訂正・開示の求め](./requests.md)にあります。
求めは、様式のほか、免責事項のメールの宛先でも受けます。
個人情報の扱いへの苦情も、同じ様式か、同じメールの宛先で受けます。

## 年齢

16 歳未満の人からの申し出は受けません。
18 歳未満の人からの申し出は、親または保護者の同意があるときに限って受けます。
16 歳未満の人の申し出だと分かったときは、求めが無くても、その issue を消します。

過去の版は、公開の履歴に残ります。
