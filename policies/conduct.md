# 行動の決まり

最終更新：2026-11-19。

この決まりは、このリポジトリの issue と PR と、ここで始めた協力のすべての場に当てはまります。
運営者にも当てはまります。

## 求める振る舞い

- 人ではなく、主張と根拠について書きます。
- 誤りを指摘されたときは、記録を消さずに直します。
- 出どころの分かるものだけを根拠に挙げます。
- 言語モデルを使ったときは、何に使ったかを書きます。
- 他人の未公開の稿や着想を、本人の合意なしに使いません。

## 認めない振る舞い

- 嫌がらせ、脅し、人を貶める言葉。
- 国籍、性別、年齢、障害、信条などを理由にした差別。
- 他人の個人情報を、本人の合意なしに書くこと。
- 他人の名誉や信用を傷つけること。
- データや出どころを偽ること。
- 金銭やほかの対価を求めること、申し出ること。

## 知らせ方

この決まりに反する振る舞いは、[削除・訂正・開示の求め](https://github.com/cpsbvbng26-dotcom/research-collaboration/issues/new?template=request.yml)の様式で知らせることができます。
公開の場で書けないときは、その様式の種類で「非公開の連絡を求める」を選びます。
手順は[削除・訂正・開示の求め](./requests.md)の「公開できない求め」にあります。
その節は、issue を開かずにメールの宛先で知らせる道も書いています。

## 運営者がすること

運営者は、すべての知らせを読みます。
運営者は、反した書き込みを隠すか消し、issue の書き込みを止め、アカウントをこのリポジトリから締め出すことがあります。
どれも GitHub の機能で行います。
運営者は、したことを、差し支えのない範囲でその issue に書きます。
運営者自身が反したときも、同じ扱いにします。
