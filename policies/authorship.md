# 著者と貢献

最終更新：2026-11-18。

## 役割で示す

協力した人は、何をしたかの役割で示します。
役割の名は、CRediT（Contributor Roles Taxonomy）の語をそのまま使います。
誰がどの役割を担ったかは、その協力の issue に書き、出すものにも書きます。

## 著者

著者になるのは、出す先の場が定める著者の基準を満たし、出すことに同意した人です。
基準を満たさない協力は、謝辞と役割の一覧で示します。
著者の並びは、出す前に、著者全員でその協力の issue で決めます。

## Claude は著者にしない

Claude は著者ではありません。
Claude は役割の一覧にも入りません。
ほかの言語モデルも同じです。

## 言語モデルの使い方の開示

運営者は、作業に Claude Code を使います。
出すものには、言語モデルを何に使ったかを書きます。
協力する人が言語モデルを使ったときも、何に使ったかを、その協力の issue に書く形にしています。
開示は消しません。

## 名の示し方

名は、本人が選んだ形で示します。
実名でも、GitHub のアカウント名でも示せます。
運営者は、本名を求めません。
名の示し方は、[削除・訂正・開示の求め](./requests.md)で、あとから変えられます。
法令の読み方は、[法令の整理](./law.md)の「著作権法」にあります。

## 責任

著者は、自分が担った部分に責任を持ちます。
証明や数値の誤りが見つかったときは、出した稿を書き換えず、正誤表で直します。
